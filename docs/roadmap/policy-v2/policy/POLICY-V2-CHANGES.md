# Policy base version 2 (2026-10-07)

Drop-in replacement for `policy/`. Built by script from the version-1 files plus approved amendment `0001`; nothing was retyped by hand. Verified against the repository: all three files load through `tribunal.loader.load_policies`, briefs build for corpus cases 101 and 201, `pipeline.confidence_floor` still parses, and `tests.test_referee / test_brief / test_money / test_prepass / test_facts / test_loader / test_language / test_pipeline / test_transcript / test_grade` (556 tests) pass with these files in place and `BASE_VERSION = 2`.

## What the code must do to use it (see the iteration plan, item 41)

1. `tribunal/policy_versions.py`: `BASE_VERSION = 2`.
2. `data/PUBLIC-CONTRACT.md` (additive revision; `schema_version` stays 1.2.0 because `prepass.detect_schema_version_mismatch` treats a case/artifact version difference as a defect): `trip_record.platform_policy` (optional object: `grace_after_match_sec`, `advance_grace_before_scheduled_sec`, `free_wait_sec`, `no_show_threshold_sec`, `cancellation_fee_sgd`, `rider_gross_cancellation_fee_sgd`, `waiting_fee_sgd`, `fee_goes_to`, `arrival_marker`, `source`); `trip_record.accepted_at` (already present, now cited by POL-NS-10); `trip_record.scheduled_at` (nullable); `trip_record.events[]` (`event_type`, `at`, `detail`, `source`); GPS point `accuracy_m` nullable; `dispute.safety_flag` and `dispute.complaint_flag` (booleans set by intake, cited by POL-GEN-05/06); policy files now carry 8 / 10 / 13 = 31 clauses and the top-level keys `execution_threshold_sgd`, `policy_sources` (general) and `integrity` (no_show) - update the contract's clause counts and key lists.
3. `tribunal/brief.py`: drop every `sources` key from the injected policies (top level, clauses, `fee_schedule`, `fare_model`); `platform_policy.source` values are opaque codes by contract; extend `tests/test_no_leakage.py` so that the injected policy view contains no `sources` key, no sealed-set case number and none of the words 'sealed', 'DISP-002', 'organiser', 'Ryde Help Centre'. `tribunal/money.py` and `tribunal/brief.py`: read the fee, the free wait and the waiting fee from `platform_policy`, falling back to `fee_schedule.defaults`; the brief carries a `platform_policy_in_force` block with its `source`.
4. `tribunal/prepass.py`: read every weight from the `integrity.weights` block (it holds all 19 codes) instead of `CODE_WEIGHTS`; derive the three GPS_GAP variants by computing gap length and position from the trace and the waiting window.
5. One-off backfill `eval/backfill_platform_policy.py` (delivered in this bundle under `eval/`; run on a copy of the main package: 59 NO_SHOW_CHARGE cases written, codex `index.json` sha256 entries refreshed, loader/brief/money/facts/prepass/referee/pipeline/language tests pass afterwards): every existing NO_SHOW_CHARGE case gets the parameters it was authored under (free wait 300 s, 480 s at AIRPORT; fee = the version-1 greater-of result; source `AUTHORED-V1`); case 901 gets the organisers' block (300 s / 480 s / $5.0 / DRIVER / GPS_AUTO; source `RECORD-PLATFORM`). Answer keys are not edited. **Note:** the script rewrites the eight wild-v2 case files, so `tests/test_sealed_set_wild_v2.py` (bundle digest table) fails until wild-v2 is re-registered as a development set with a new import note, which plan item 12 requires anyway; run the backfill after that re-registration, not before.
6. `eval/external/ryde/convert.py`: map `cancellation_policy` to `platform_policy` and `app_events` to `trip_record.events[]`.
7. Tests to update (and the contract's clause counts): `tests/test_policy_versions.py` (version-1 and amendment-0001 fixtures), `tests/test_policy_gaps*.py` (next amendment number is 0001 under base 2), the recorded-digest tests (`test_offline_replay`, `test_policy_versions` digest checks, `test_sealed_set*`) after the full rerun, `test_readme_figures` and `test_ui_build` after `ui.build`.
