# 积分台账

每位成员总共 1000 活动 credits；同一成员的 WorkBuddy 与 CodeBuddy 使用按共享额度池管理，不能分别预算 1000。团队总名义额度为 3000，但成员之间不假定可以互转或共享。余额、有效期及 Miora 是否也从同一池扣减，以各成员账号的 Usage 页面实际变化为准。
建议每人跨 WorkBuddy 与 CodeBuddy 合并分配：开工50、开发500、联调200、提交100、应急150。实际消耗未知，这是共享池的预算上限而非扣分预测。

活动依据：新加坡活动材料将额度表述为每位注册参赛者一份 1,000 credits，用于 CodeBuddy、WorkBuddy 和 Miora；因此预算不按三个产品分别乘三。实际扣减关系以账号 Usage 页面为最终证据。

独立 API 账本：供应商/模型、输入输出 token、单价及日期、币种、实际账单、单次预算和总预算。未经确认不把活动 credits 折算成 API 费用。
