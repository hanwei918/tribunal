Get started

Python 3.9 and 3.13 (both tested), standard library only; requirements.txt declares no dependency. You need the submitted repository. A TokenHub key is needed only to run a new case: TOKENHUB_API_KEY, or a .env copied from .env.example.

pip install -r requirements.txt

Reproduce every number

python3 -m eval.v8_report --report
python3 -m eval.development_sets --report
python3 -m eval.sealed_report --set sealed-v4
python3 -m unittest discover -s tests

No key. On Linux the tests that rebuild case 111's brief skip by design: glibc and macOS libm differ in the last place of one number.

Run a case

python3 -m eval.development_sets --set dev-v8 --cases 5051 --parallel-calls --concurrency 2 --timeout 900 --prompts-dir prompts/v2 --runs-dir /tmp/tribunal-runs

A version-8 run needs --prompts-dir prompts/v2; the set fixes the rest. Off by default: --integrity-gate, --precedents, --verify-drafts. Each is refused for sealed sets.

Operations

These read the version-6 runs.

python3 -m ops.queue --run-dir runs/policy-v6/deepseek-deepseek-flash
python3 -m ops.escalation --run-dir <dir> --case N --format md
python3 -m ops.risk --case N

Lanes and what is due; the reviewer's packet; risk signals. Closing a case, an evidence window and an appeal check take the case's own arguments, and each case page's review form builds the exact command. None calls a model.

WorkBuddy connector

A read-only MCP server with three tools - tribunal_case, tribunal_queue, tribunal_packet. No key, no network; it refuses the sealed sets. Add to your WorkBuddy mcp.json:

{
  "mcpServers": {
    "tribunal": {
      "command": "python3",
      "args": ["/absolute/path/to/Tribunal/integrations/workbuddy/tribunal_mcp_server.py"]
    }
  }
}

Build the site

python3 -m ui.site.build
python3 -m ui.v8.build
python3 -m ui.v6.build
python3 -m ui.v2.build
python3 -m ui.build

Writes the version-8 and version-6 case pages, the reviewer's pages and the queue under ui/dist/, and the benchmark replay. --check compares with the committed pages. Build on macOS.

Version 6 (history)

python3 -m eval.v6_runs --report
python3 -m eval.business_value --report
python3 -m eval.run_benchmark --cases 101 --policy-version 6 --runs-dir /tmp/tribunal-runs

Version 6 is the team's own policy, frozen 2026-10-11; the submission applies version 8. Pass --policy-version 6; the default is version 1.


A clear system.

Four C4 diagrams, checked box by box against the code. Click to open full size.


Small on purpose.

Language

Python 3.9 and 3.13 (both tested), standard library only.

Model

deepseek/deepseek-flash, Tencent Cloud TokenHub.

Agents

Six AI calls per case by design: two lawyers and four judge drafts (a draft that fails its check is retried once); two when a v2.1 rule stops the case before the judge.

Hosting

Static pages on Tencent EdgeOne Pages; the try-it phone replays recorded version-8 runs in the browser and calls no model.

Integration

WorkBuddy MCP connector, read-only.

Records

Saved runs and a log where any change shows.
