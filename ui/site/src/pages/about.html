Four lessons.

01

Test outside the sandbox

Inside the sandbox, tests were slow and sometimes failed for no real reason.

02

One task per session

Small tasks kept the AI focused.

03

Check the 'all green'

Don't trust 'all tests pass' until you've seen it yourself.

04

Never open the key

Keep the test answers hidden, and run the test only once.
