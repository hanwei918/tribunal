The AgentThat SettlesRide Disputes

Two AI lawyers argue, code checks the facts, an AI judge rules. Typically decided in under 3 minutes, for about 4 cents.

Applies Ryde's own Dispute Resolution Policy v2.1 with Ryde's answers of 2026-10-14 (policy version 8). Sealed set, run at version 7: 30/30, Wilson 95% [88.6%, 100%] -- written by the team's own development assistant, so not an independent benchmark.

Six steps. Every one checked.

The AI argues and rules. Code keeps it honest.

#1 BRIEF

One Evidence Pack

All the evidence goes into one pack. Both sides get exactly the same copy.

#2 ARGUE

Two AI Lawyers

One AI lawyer speaks for the rider, one for the driver.

#3 CHECK

Fact-Check by Code

Code checks every point they make. No proof, it doesn't count.

#4 VOTE

Four Rulings

The AI judge rules four times, once with the two sides swapped. Three must agree.

#5 HOLD

Money Held

Not sure? It doesn't rule, and a person decides. Over SGD 50, a safety flag, or a route deviation over 2 km? A person decides.

#6 RECORD

On the Record

Every step is logged, and any change to the log shows.
