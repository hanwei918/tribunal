快速开始

Python 3.9.6 到 3.13，只用标准库；requirements.txt 没有声明任何依赖。需要提交的代码仓库(GitHub 仓库为私有)。只有运行新案件时才需要 TokenHub key：设置 TOKENHUB_API_KEY，或从 .env.example 复制一份 .env。

pip install -r requirements.txt

复现全部数字

python3 -m eval.v6_runs --report
python3 -m eval.business_value --report
python3 -m unittest discover -s tests

无需 key。在 Linux 上，重建案例 111 简报的测试会按设计跳过：glibc 与 macOS libm 在一个数字的最后一位上不同。

运行一个案件

python3 -m eval.run_benchmark --cases 101 --policy-version 6 --runs-dir /tmp/tribunal-runs

务必加上 --policy-version 6，默认是第 1 版。以下开关默认关闭：--integrity-gate、--precedents、--verify-drafts，且对封存集一律拒绝。

运营命令

python3 -m ops.queue --run-dir runs/policy-v6/deepseek-deepseek-flash
python3 -m ops.escalation --run-dir <dir> --case N --format md
python3 -m ops.risk --case N

分流与到期情况、审核员材料包、风险信号。结案、补证窗口和申诉检查需要案件自己的参数，每个案件页的审核表单会生成完整命令。以上都不调用模型。

WorkBuddy 连接器

一个只读的 MCP 服务器，提供三个工具：tribunal_case、tribunal_queue、tribunal_packet。无需 key、无需联网，并拒绝访问封存集。在 WorkBuddy 的 mcp.json 中加入：

{
  "mcpServers": {
    "tribunal": {
      "command": "python3",
      "args": ["/absolute/path/to/Tribunal/integrations/workbuddy/tribunal_mcp_server.py"]
    }
  }
}

构建网站

python3 -m ui.v2.build
python3 -m ui.build

在 ui/dist/ 下生成队列、案件页和基准回放。--check 会与已提交的页面比对。请在 macOS 上构建。
