Try it.

Change a recorded case and see what Tribunal does with it. The code checks run here in your browser. The AI panel runs on our server when it is switched on.

This page runs the team's version-6 policy in your browser; the submission applies version 8.


1. Pick a case.

Each one is a recorded case. You change the story; the GPS trace and the fare stay as recorded.


2. Change the story.

Write your own words, or start from an idea. The case text is English, and the threat checks are written for English, so a threat in Chinese is not detected.

The record

The in-app chat

    Download the scenario


    3. What plain code finds.

    The real Tribunal code, in Python, in your browser. No AI, no server.


    4. The AI panel.

    Two AI lawyers argue, code checks every point, and the judge rules four times.

    Live run

    Your scenario goes to the same model with the same settings as the recorded runs. It takes 2 to 5 minutes and costs us about 6 US cents.

    Live run is off right now

    The AI panel needs our server and a model key, and it is not connected at the moment. You can still run your scenario yourself: download it above, then in the repository run

    python3 -m tryit.server --once tribunal-scenario.json

    It needs a TokenHub key in TOKENHUB_API_KEY. Everything else is the standard library.

    Scenarios are test cases. Nothing is sent to any rider or driver, and no money moves.
