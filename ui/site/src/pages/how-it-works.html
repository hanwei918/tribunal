How a dispute
is decided.

The AI argues and rules. Code gathers the evidence, checks the facts, counts the votes and calls in a person when needed.


Side by side.

Most AI judges are one model reading one complaint. Here are eight things it can't promise, and how Tribunal does them.

Single-model judgeTribunal
Adversarial, not one-sidedOne AI reads the complaint and decides.Each side gets its own AI lawyer, and both work from the same evidence pack. Their instructions are identical except for whose side they're on, and the code checks that.Case 5051: 3 points for the rider, 8 for the driver.
Every citation checked by codeWhatever the AI quotes is taken on trust.Before the judge sees anything, plain code checks that every point names real evidence and a real rule. If not, it's thrown out.No AI gets to decide what counts as evidence.
Four rulings, one with the sides swappedOne answer, with no test of bias.The AI judge rules four times. In one of them the rider and driver swap places, to catch any bias. Three of the four must agree, and code checks each one.33 of 34 at version 8.
Money computed by codeThe model names an amount.Distances, waiting time and fares are worked out by code, not guessed by the AI. Even a person can only pick from the amounts code allows.Case 5051: 345 s of waiting, driver paid SGD 5.00.
Knows when to stopAlways gives an answer, even when unsure.If the judge isn't sure or its answers split, it doesn't rule: the money is frozen and a person decides. A safety flag, a value over SGD 50 or a route deviation over 2 km goes to a person before the judge is asked.In the sixth sealed set (sealed-v4, version 7), all 9 cases that needed a person got one.
Hard to foolCan be tricked by instructions hidden in a complaint.A fake rule hidden in the chat doesn't work. Quoting a rule that doesn't exist sends the case to a person instead of changing the outcome -- which also means a party can push a case to a person this way.6 attack tests, version 6: 0 rulings flipped (5 unchanged, 1 sent to a person).
Every step on the recordAn answer, but no way to check how it got there.Each case keeps a fingerprint of the evidence, the instructions and the code that ran. Anyone can replay it; this site does exactly that, without calling any AI.The figures on this site are re-checked by the test suite.
Measured honestlyScored on its own development data.The system was never developed against the sealed test sets; each was run once, on frozen code, and its score is reported on its own. One was opened by the policy owner's assistant before the freeze; the Results page says which.Sealed set (version 7): 30/30, written by the team's own development assistant.

Eight stages.

Only two stages use AI: the two lawyers and the judge. The rest is plain code.

  1. 01

    Load

    Open the case and check the files are complete.

    loader.py
  2. 02

    Weigh and measure

    Weak evidence counts for less. GPS becomes distance and waiting time.

    prepass.py, facts.py
  3. 03

    Evidence pack

    One pack for everyone, with plates, phone numbers and e-mails masked.

    brief.py
  4. 04

    Two AI lawyers

    One for the rider, one for the driver. Same instructions, opposite sides.

    prompts/v2/advocate
  5. 05

    Authority gate

    A safety flag, a value over SGD 50 or a route deviation over 2 km goes to a person; the lawyers have prepared the case file and the judge is not asked.

    pipeline.py
  6. 06

    Fact-check

    Throws out any point without real proof. Doesn't pick a winner.

    referee.py
  7. 07

    Four rulings

    Rules four times, once with the sides swapped. Three must agree.

    prompts/v2/judge
  8. 08

    The bar and a person

    Below the confidence v2.1 asks (0.80; 0.95 with a fraud flag), or with the drafts split, the money is held and a person decides.

    pipeline.py

Why it can be trusted.

01

Same evidence for both sides

Both lawyers and the judge read the very same evidence pack, and its fingerprint is saved.

Case 5051: 7 pieces of evidence, one pack.

02

A lawyer for each side

Their instructions differ only in whose side they're on. Code makes sure of it.

Case 5051: 3 points for the rider, 8 for the driver.

03

Facts checked by code

Facts are checked by plain code, not by another AI.

Case 5051: 10/11 claims kept.

04

Four rulings, one with sides swapped

Swapping sides shows whether the judge is biased. A tie goes to a person.

33 of 34 at version 8.

05

When unsure, hold the money

If it isn't sure, it doesn't rule. Over SGD 50, a safety flag, or a route deviation over 2 km, a person decides.

28 of 40 ruled by the AI; 12 to a person -- 5 stopped by a v2.1 rule before the judge, 6 the panel sent on, 1 without a majority.

06

Everything on the record

Every question, answer and check is logged, and any change to the log shows.

Every case page on this site is built from the saved run records.

Fraud signals

Flags repeat claimants. Matched the answer key on all 8 test cases, decoys included (version 6).

Evidence collection

A standalone command (ops/evidence.py) gathers a case's evidence from the mocked sources; the pipeline reads the case file.
